Datasheet (BHD26)

Never invent a code in the field: if it is missing, write the full name.

  • One row = one observation. Never leave a cell empty: write NA or ND. 0 means searched and not found.
  • No unit in the cell. Decimal separator is a point. Pencil 2H, filled in on the spot.
  • Date AAAA-MM-JJ (2026-09-16); time HH:MM, 24 h, UTC+1.
  • Latitude and longitude in decimal degrees, WGS 84, 5 decimals; GPS accuracy in metres.

Identifiers

  • Transect: BHD26_TR01 to TR04; quadrat on a transect: BHD26_TR02_Q3
  • Sample (feces, tick): BHD26_E001 (continuous numbering)
  • Observer: 3 unique initials (e.g. ZBO)

Controlled vocabularies and codes

  • Sign type V3: VIS, AUD, EMP (footprint), FEC (feces), LAT, TER (burrow), GRT, POI, PLU, OSS, CAD, PEL, MUE, PHO
  • Habitat V1; substrate V2 (SAB, LIM, GRV, ROC, GYP, ARG, LIT); sex and age V4; identification reliability V5 (1 certain, 2 probable, 3 possible)
  • Species codes: JAJA Jaculus jaculus, PSOB Psammomys obesus, MESH Meriones shawii, CTGU Ctenodactylus gundi, GERSP Gerbillus sp. (genus, determination in hand). Going down to genus is always preferable to an invented species.

Darwin Core: an event row per transect walked (eventID, eventDate, eventTime, samplingProtocol, sampleSizeValue, sampleSizeUnit, decimalLatitude, decimalLongitude, coordinateUncertaintyInMeters, geodeticDatum, habitat, recordedBy, equipe) and an occurrence row per observation (scientificName, codeEspece, individualCount, sex, lifeStage, basisOfRecord, identificationQualifier). A transect with no sign is still an event row with zero occurrences.

Fiche de saisie (BHD26)

N'inventez jamais un code sur le terrain : s'il manque, écrire le nom complet.

  • Une ligne = une observation. Jamais de case vide : écrire NA ou ND. 0 signifie recherché et non trouvé.
  • Pas d'unité dans la cellule. Décimale = point. Crayon 2H, rempli sur place.
  • Date AAAA-MM-JJ (2026-09-16) ; heure HH:MM sur 24 h, UTC+1.
  • Latitude et longitude en degrés décimaux, WGS 84, 5 décimales ; précision GPS en mètres.

Identifiants

  • Transect : BHD26_TR01 à TR04 ; quadrat sur transect : BHD26_TR02_Q3
  • Échantillon (fèces, tique) : BHD26_E001 (numérotation continue)
  • Observateur : initiales sur 3 lettres, uniques (ex. ZBO)

Vocabulaires contrôlés et codes

  • Type d'indice V3 : VIS, AUD, EMP (empreinte), FEC (fèces), LAT, TER (terrier), GRT, POI, PLU, OSS, CAD, PEL, MUE, PHO
  • Habitat V1 ; substrat V2 (SAB, LIM, GRV, ROC, GYP, ARG, LIT) ; âge et sexe V4 ; fiabilité de l'identification V5 (1 certaine, 2 probable, 3 possible)
  • Codes espèces : JAJA Jaculus jaculus, PSOB Psammomys obesus, MESH Meriones shawii, CTGU Ctenodactylus gundi, GERSP Gerbillus sp. (genre, détermination en main). Descendre au genre est toujours préférable à une espèce inventée.

Darwin Core : une ligne événement par transect parcouru (eventID, eventDate, eventTime, samplingProtocol, sampleSizeValue, sampleSizeUnit, decimalLatitude, decimalLongitude, coordinateUncertaintyInMeters, geodeticDatum, habitat, recordedBy, equipe) et une ligne occurrence par observation (scientificName, codeEspece, individualCount, sex, lifeStage, basisOfRecord, identificationQualifier). Un transect sans indice reste une ligne événement avec zéro occurrence.

استمارة البيانات (BHD26)

لا تخترع رمزًا في الميدان أبدًا: إن كان الرمز غير موجود فاكتب الاسم الكامل.

  • سطر واحد = ملاحظة واحدة. لا تترك خانة فارغة أبدًا: اكتب NA أو ND. الصفر يعني أنه جرى البحث ولم يُعثر على شيء.
  • لا وحدة داخل الخانة. الفاصل العشري نقطة. قلم رصاص 2H، وتُملأ الاستمارة في المكان.
  • التاريخ بصيغة AAAA-MM-JJ (2026-09-16)؛ الوقت HH:MM بنظام 24 ساعة، التوقيت UTC+1.
  • خط العرض وخط الطول بالدرجات العشرية، WGS 84، خمس خانات عشرية؛ دقة GPS بالأمتار.

المعرّفات

  • المقطع: BHD26_TR01 إلى TR04؛ مربع القياس على مقطع: BHD26_TR02_Q3
  • العيّنة (فضلات، قراد): BHD26_E001 (ترقيم متصل)
  • المراقب: ثلاثة أحرف أولى فريدة (مثل ZBO)

المفردات المضبوطة والرموز

  • نوع العلامة V3: VIS وAUD وEMP (أثر قدم) وFEC (فضلات) وLAT وTER (جحر) وGRT وPOI وPLU وOSS وCAD وPEL وMUE وPHO
  • الموئل V1؛ الركيزة V2 (SAB وLIM وGRV وROC وGYP وARG وLIT)؛ الجنس والعمر V4؛ موثوقية التعرّف V5 (1 مؤكد، 2 محتمل، 3 ممكن)
  • رموز الأنواع: JAJA Jaculus jaculus، PSOB Psammomys obesus، MESH Meriones shawii، CTGU Ctenodactylus gundi، GERSP Gerbillus sp. (الجنس، والتحديد في اليد). النزول إلى مستوى الجنس أفضل دائمًا من نوع مختلَق.

Darwin Core: سطر حدث لكل مقطع جرى قطعه (eventID وeventDate وeventTime وsamplingProtocol وsampleSizeValue وsampleSizeUnit وdecimalLatitude وdecimalLongitude وcoordinateUncertaintyInMeters وgeodeticDatum وhabitat وrecordedBy وequipe) وسطر ظهور لكل ملاحظة (scientificName وcodeEspece وindividualCount وsex وlifeStage وbasisOfRecord وidentificationQualifier). المقطع الذي لا توجد فيه علامة يبقى سطر حدث مع صفر ظهور.
