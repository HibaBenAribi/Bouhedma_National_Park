Datasheet (BHD26)

Event table, one row per sampling unit (listening point): eventID, eventDate (YYYY-MM-DD), eventTime (HH:MM, UTC+1), samplingProtocol, sampleSizeValue, sampleSizeUnit, decimalLatitude, decimalLongitude (WGS 84, 5 decimals), coordinateUncertaintyInMeters, geodeticDatum, locality, habitat, recordedBy, equipe.

Occurrence table, one row per observation: occurrenceID, eventID, scientificName, vernacularName, codeEspece, individualCount, sex, lifeStage, basisOfRecord, identificationQualifier, identifiedBy, associatedMedia, occurrenceRemarks.

  • Station: BHD26_AC01 and following. Observer: three unique initials (for example ZBO). Team: A, B, C or D.
  • Evidence type (V3): AUD (heard). Reliability (V5): 1 certain, 2 probable, 3 possible.
  • Habitat (V1), for example SAV, STA, JEB, OUE, PTE.
  • Weather (V6): cloud in oktas 0 to 8, wind Beaufort 0 to 12, rain 0 / 1 / 2, temperature in degrees C, moon NL / PQ / PL / DQ.
  • Species codes: STCA Struthio camelus, AMDE Ammomanes deserti, CUCU Cursorius cursor, BUAS Bubo ascalaphus, GACR Galerida cristata, GATH Galerida theklae. Unidentified bird: AVISP. A species not in the list is written in full.
  • Rules: one line is one observation; never leave a cell empty (NA or ND); 0 means searched and not found; effort is recorded even with no detection.

Fiche de données (BHD26)

Table Événement, une ligne par unité d'échantillonnage (point d'écoute) : eventID, eventDate (AAAA-MM-JJ), eventTime (HH:MM, UTC+1), samplingProtocol, sampleSizeValue, sampleSizeUnit, decimalLatitude, decimalLongitude (WGS 84, 5 décimales), coordinateUncertaintyInMeters, geodeticDatum, locality, habitat, recordedBy, equipe.

Table Occurrence, une ligne par observation : occurrenceID, eventID, scientificName, vernacularName, codeEspece, individualCount, sex, lifeStage, basisOfRecord, identificationQualifier, identifiedBy, associatedMedia, occurrenceRemarks.

  • Station : BHD26_AC01 et suivantes. Observateur : initiales sur 3 lettres, uniques (par exemple ZBO). Équipe : A, B, C ou D.
  • Type d'indice (V3) : AUD (animal entendu). Fiabilité (V5) : 1 certaine, 2 probable, 3 possible.
  • Habitat (V1), par exemple SAV, STA, JEB, OUE, PTE.
  • Météo (V6) : nuages en octas 0 à 8, vent Beaufort 0 à 12, pluie 0 / 1 / 2, température en °C, lune NL / PQ / PL / DQ.
  • Codes espèces : STCA Struthio camelus, AMDE Ammomanes deserti, CUCU Cursorius cursor, BUAS Bubo ascalaphus, GACR Galerida cristata, GATH Galerida theklae. Oiseau non déterminé : AVISP. Une espèce hors liste s'écrit en toutes lettres.
  • Règles : une ligne = une observation ; jamais de case vide (NA ou ND) ; 0 signifie recherché et non trouvé ; l'effort se note même sans détection.

استمارة البيانات (BHD26)

Event: eventID, eventDate (YYYY-MM-DD), eventTime (HH:MM, UTC+1), samplingProtocol, sampleSizeValue, sampleSizeUnit, decimalLatitude, decimalLongitude, coordinateUncertaintyInMeters, geodeticDatum, locality, habitat, recordedBy, equipe

جدول الحدث: صف واحد لكل وحدة أخذ عينات (نقطة إصغاء). الحقول أعلاه بالإنجليزية كما في القاموس. التاريخ بصيغة AAAA-MM-JJ، والتوقيت HH:MM بتوقيت UTC+1، والإحداثيات WGS 84 بخمس خانات عشرية.

Occurrence: occurrenceID, eventID, scientificName, vernacularName, codeEspece, individualCount, sex, lifeStage, basisOfRecord, identificationQualifier, identifiedBy, associatedMedia, occurrenceRemarks

جدول المشاهدة: صف واحد لكل مشاهدة، مرتبط بمعرّف الحدث eventID.

  • المحطة: BHD26_AC01 وما يليها. المراقب: ثلاثة أحرف أولى فريدة (مثل ZBO). الفريق: A أو B أو C أو D.
  • نوع الدليل (V3): AUD (حيوان مسموع). الموثوقية (V5): 1 مؤكدة، 2 محتملة، 3 ممكنة.
  • الموطن (V1)، مثل SAV وSTA وJEB وOUE وPTE.
  • الطقس (V6): الغيوم بالأوكتا من 0 إلى 8، الرياح بمقياس بوفورت من 0 إلى 12، المطر 0 / 1 / 2، الحرارة بالدرجة المئوية، القمر NL / PQ / PL / DQ.
  • رموز الأنواع: STCA Struthio camelus، AMDE Ammomanes deserti، CUCU Cursorius cursor، BUAS Bubo ascalaphus، GACR Galerida cristata، GATH Galerida theklae. طائر غير محدد: AVISP. النوع غير الموجود في القائمة يُكتب بالاسم الكامل.
  • القواعد: سطر واحد لكل مشاهدة؛ لا خانة فارغة أبدًا (NA أو ND)؛ الصفر يعني بحثنا ولم نجد؛ يُسجَّل الجهد حتى عند غياب أي اكتشاف.
