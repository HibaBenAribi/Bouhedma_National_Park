Datasheet (BHD26)

Event table, one row per sampling unit (for example a route surveyed): eventID, eventDate (YYYY-MM-DD), eventTime (HH:MM, UTC+1), samplingProtocol, sampleSizeValue, sampleSizeUnit, decimalLatitude, decimalLongitude (WGS 84, 5 decimals), coordinateUncertaintyInMeters, geodeticDatum, locality, habitat, recordedBy, equipe.

Occurrence table, one row per observation: occurrenceID, eventID, scientificName, vernacularName, codeEspece, individualCount, sex, lifeStage, basisOfRecord, identificationQualifier, identifiedBy, associatedMedia, occurrenceRemarks.

  • Species codes: ORDA Oryx dammah, NADA Nanger dama mhorr, GADO Gazella dorcas. One species per line, never "3 gazelles + 1 oryx" in one cell.
  • Evidence type (V3): VIS seen, EMP footprint, FEC droppings, LAT latrine.
  • Sex and age (V4): M / F / I; AD, SA, JU, JA, IND. Reliability (V5): 1 certain, 2 probable, 3 possible.
  • Habitat (V1), for example SAV, GLA, ENC, PTE. Observer: three unique initials. Team: A, B, C or D.
  • Rules: never leave a cell empty (NA or ND); no unit in the cell; decimal point, not comma; 0 means searched and not found.

Fiche de données (BHD26)

Table Événement, une ligne par unité d'échantillonnage (par exemple un parcours effectué) : eventID, eventDate (AAAA-MM-JJ), eventTime (HH:MM, UTC+1), samplingProtocol, sampleSizeValue, sampleSizeUnit, decimalLatitude, decimalLongitude (WGS 84, 5 décimales), coordinateUncertaintyInMeters, geodeticDatum, locality, habitat, recordedBy, equipe.

Table Occurrence, une ligne par observation : occurrenceID, eventID, scientificName, vernacularName, codeEspece, individualCount, sex, lifeStage, basisOfRecord, identificationQualifier, identifiedBy, associatedMedia, occurrenceRemarks.

  • Codes espèces : ORDA Oryx dammah, NADA Nanger dama mhorr, GADO Gazella dorcas. Une espèce par ligne, jamais « 3 gazelles + 1 oryx » dans une case.
  • Type d'indice (V3) : VIS animal vu, EMP empreinte, FEC crotte, LAT latrine.
  • Sexe et âge (V4) : M / F / I ; AD, SA, JU, JA, IND. Fiabilité (V5) : 1 certaine, 2 probable, 3 possible.
  • Habitat (V1), par exemple SAV, GLA, ENC, PTE. Observateur : initiales sur 3 lettres, uniques. Équipe : A, B, C ou D.
  • Règles : jamais de case vide (NA ou ND) ; pas d'unité dans la cellule ; décimale = point ; 0 signifie recherché et non trouvé.

استمارة البيانات (BHD26)

Event: eventID, eventDate (YYYY-MM-DD), eventTime (HH:MM, UTC+1), samplingProtocol, sampleSizeValue, sampleSizeUnit, decimalLatitude, decimalLongitude, coordinateUncertaintyInMeters, geodeticDatum, locality, habitat, recordedBy, equipe

جدول الحدث: صف واحد لكل وحدة أخذ عينات (مثل مسار مُسِح). أسماء الحقول بالإنجليزية كما في القاموس. التاريخ بصيغة AAAA-MM-JJ، والتوقيت HH:MM بتوقيت UTC+1، والإحداثيات WGS 84 بخمس خانات عشرية.

Occurrence: occurrenceID, eventID, scientificName, vernacularName, codeEspece, individualCount, sex, lifeStage, basisOfRecord, identificationQualifier, identifiedBy, associatedMedia, occurrenceRemarks

جدول المشاهدة: صف واحد لكل مشاهدة، مرتبط بمعرّف الحدث eventID.

  • رموز الأنواع: ORDA Oryx dammah، NADA Nanger dama mhorr، GADO Gazella dorcas. نوع واحد في كل سطر، ولا يُكتب أبدًا «3 غزلان + 1 مها» في خانة واحدة.
  • نوع الدليل (V3): VIS حيوان مرئي، EMP أثر قدم، FEC فضلات، LAT مرحاض.
  • الجنس والعمر (V4): M / F / I؛ AD وSA وJU وJA وIND. الموثوقية (V5): 1 مؤكدة، 2 محتملة، 3 ممكنة.
  • الموطن (V1)، مثل SAV وGLA وENC وPTE. المراقب: ثلاثة أحرف أولى فريدة. الفريق: A أو B أو C أو D.
  • القواعد: لا خانة فارغة أبدًا (NA أو ND)؛ لا وحدة قياس داخل الخانة؛ الفاصلة العشرية نقطة لا فاصلة؛ الصفر يعني بحثنا ولم نجد.
