Datasheet (BHD26)

Never invent a code in the field: if it is missing, write the full name.

  • One row = one observation. Never leave a cell empty: write NA or ND. 0 means searched and not found.
  • No unit in the cell (forearm length in a column headed mm). Decimal separator is a point. Pencil 2H, filled in on the spot.
  • Date AAAA-MM-JJ (2026-09-16); time HH:MM, 24 h, UTC+1.
  • Latitude and longitude in decimal degrees, WGS 84, 5 decimals; GPS accuracy in metres.

Identifiers

  • Sample (feces or other): BHD26_E001 (continuous numbering)
  • Observer: 3 unique initials (e.g. ZBO)
  • The dictionary defines no dedicated station identifier for bat nets.

Controlled vocabularies and codes

  • Species: RHCY, RHHI, other working codes as listed in the analysis section; default CHISP
  • Sex and age V4: M, F, I; AD, SA, JU, JA, IND; identification reliability V5: 1 certain, 2 probable, 3 possible
  • Weather V6, recorded at the start and at the end of each sampling unit: cloud cover in oktas 0 to 8; wind Beaufort 0 to 12; rain 0, 1, 2; temperature in whole °C; moon NL, PQ, PL, DQ

Darwin Core: an event row per station-night (eventID, eventDate, eventTime, samplingProtocol, sampleSizeValue, sampleSizeUnit, decimalLatitude, decimalLongitude, habitat, recordedBy) and an occurrence row per bat (scientificName, codeEspece, individualCount, sex, lifeStage, identificationQualifier, occurrenceRemarks). A night with no capture is still an event row with zero occurrences.

Fiche de saisie (BHD26)

N'inventez jamais un code sur le terrain : s'il manque, écrire le nom complet.

  • Une ligne = une observation. Jamais de case vide : écrire NA ou ND. 0 signifie recherché et non trouvé.
  • Pas d'unité dans la cellule (longueur de l'avant-bras dans une colonne intitulée mm). Décimale = point. Crayon 2H, rempli sur place.
  • Date AAAA-MM-JJ (2026-09-16) ; heure HH:MM sur 24 h, UTC+1.
  • Latitude et longitude en degrés décimaux, WGS 84, 5 décimales ; précision GPS en mètres.

Identifiants

  • Échantillon (fèces ou autre) : BHD26_E001 (numérotation continue)
  • Observateur : initiales sur 3 lettres, uniques (ex. ZBO)
  • Le dictionnaire ne définit pas d'identifiant de station dédié aux filets à chauves-souris.

Vocabulaires contrôlés et codes

  • Espèces : RHCY, RHHI, autres codes de travail listés dans la section analyse ; code par défaut CHISP
  • Âge et sexe V4 : M, F, I ; AD, SA, JU, JA, IND ; fiabilité de l'identification V5 : 1 certaine, 2 probable, 3 possible
  • Météo V6, relevée au début et à la fin de chaque unité d'échantillonnage : couverture nuageuse en octas 0 à 8 ; vent Beaufort 0 à 12 ; pluie 0, 1, 2 ; température en °C entier ; lune NL, PQ, PL, DQ

Darwin Core : une ligne événement par station-nuit (eventID, eventDate, eventTime, samplingProtocol, sampleSizeValue, sampleSizeUnit, decimalLatitude, decimalLongitude, habitat, recordedBy) et une ligne occurrence par chauve-souris (scientificName, codeEspece, individualCount, sex, lifeStage, identificationQualifier, occurrenceRemarks). Une nuit sans capture reste une ligne événement avec zéro occurrence.

استمارة البيانات (BHD26)

لا تخترع رمزًا في الميدان أبدًا: إن كان الرمز غير موجود فاكتب الاسم الكامل.

  • سطر واحد = ملاحظة واحدة. لا تترك خانة فارغة أبدًا: اكتب NA أو ND. الصفر يعني أنه جرى البحث ولم يُعثر على شيء.
  • لا وحدة داخل الخانة (طول الساعد في عمود عنوانه مم). الفاصل العشري نقطة. قلم رصاص 2H، وتُملأ الاستمارة في المكان.
  • التاريخ بصيغة AAAA-MM-JJ (2026-09-16)؛ الوقت HH:MM بنظام 24 ساعة، التوقيت UTC+1.
  • خط العرض وخط الطول بالدرجات العشرية، WGS 84، خمس خانات عشرية؛ دقة GPS بالأمتار.

المعرّفات

  • العيّنة (براز أو غيره): BHD26_E001 (ترقيم متصل)
  • المراقب: ثلاثة أحرف أولى فريدة (مثل ZBO)
  • لا يحدد القاموس معرّف محطة مخصصًا لشباك الخفافيش.

المفردات المضبوطة والرموز

  • الأنواع: RHCY وRHHI ورموز العمل الأخرى المدرجة في قسم التحليل؛ والرمز الافتراضي CHISP
  • الجنس والعمر V4: M وF وI؛ AD وSA وJU وJA وIND؛ موثوقية التعرّف V5: 1 مؤكد، 2 محتمل، 3 ممكن
  • الطقس V6، يُسجَّل في بداية كل وحدة معاينة وفي نهايتها: الغطاء السحابي بالأوكتا من 0 إلى 8؛ الرياح بمقياس بوفورت من 0 إلى 12؛ المطر 0 و1 و2؛ درجة الحرارة بالدرجة المئوية عددًا صحيحًا؛ القمر NL وPQ وPL وDQ

Darwin Core: سطر حدث لكل محطة-ليلة (eventID وeventDate وeventTime وsamplingProtocol وsampleSizeValue وsampleSizeUnit وdecimalLatitude وdecimalLongitude وhabitat وrecordedBy) وسطر ظهور لكل خفاش (scientificName وcodeEspece وindividualCount وsex وlifeStage وidentificationQualifier وoccurrenceRemarks). الليلة التي لا يُلتقط فيها شيء تبقى سطر حدث مع صفر ظهور.
