Datasheet (BHD26)

Never invent a code in the field: if it is missing, write the full name.

  • One row = one observation, one species per row. Never leave a cell empty: write NA or ND. 0 means searched and not found.
  • No unit in the cell. Decimal separator is a point. Pencil 2H, filled in on the spot.
  • Date AAAA-MM-JJ (2026-09-16); time HH:MM, 24 h, UTC+1.
  • Latitude and longitude in decimal degrees, WGS 84, 5 decimals; GPS accuracy in metres.

Identifiers

  • Light trap station: BHD26_LT01, LT02
  • Sample (insect): BHD26_E001 (continuous numbering)
  • Observer: 3 unique initials (e.g. ZBO)

Controlled vocabularies

  • Weather V6, recorded at the start and at the end of each sampling unit: cloud cover in oktas 0 to 8; wind Beaufort 0 to 12; rain 0 none, 1 drizzle, 2 shower; temperature in whole °C; moon NL, PQ, PL, DQ (new, first quarter, full, last quarter)
  • Habitat V1 (e.g. SAV, STA, JEB, OUE, BAT, PIS); sex and age V4 (M, F, I; AD, SA, JU, JA, IND); identification reliability V5 (1 certain, 2 probable, 3 possible)
  • The dictionary lists no species codes for insects: write the full name.

Darwin Core: an event row per station-night (eventID, eventDate, eventTime, samplingProtocol, sampleSizeValue, sampleSizeUnit, decimalLatitude, decimalLongitude, habitat, recordedBy) and an occurrence row per observation (scientificName, individualCount, sex, lifeStage, identificationQualifier, associatedMedia). A night with no insects is still an event row with zero occurrences.

Fiche de saisie (BHD26)

N'inventez jamais un code sur le terrain : s'il manque, écrire le nom complet.

  • Une ligne = une observation, une seule espèce par ligne. Jamais de case vide : écrire NA ou ND. 0 signifie recherché et non trouvé.
  • Pas d'unité dans la cellule. Décimale = point. Crayon 2H, rempli sur place.
  • Date AAAA-MM-JJ (2026-09-16) ; heure HH:MM sur 24 h, UTC+1.
  • Latitude et longitude en degrés décimaux, WGS 84, 5 décimales ; précision GPS en mètres.

Identifiants

  • Station de piégeage lumineux : BHD26_LT01, LT02
  • Échantillon (insecte) : BHD26_E001 (numérotation continue)
  • Observateur : initiales sur 3 lettres, uniques (ex. ZBO)

Vocabulaires contrôlés

  • Météo V6, relevée au début et à la fin de chaque unité d'échantillonnage : couverture nuageuse en octas 0 à 8 ; vent Beaufort 0 à 12 ; pluie 0 nulle, 1 bruine, 2 averse ; température en °C entier ; lune NL, PQ, PL, DQ (nouvelle, premier quartier, pleine, dernier quartier)
  • Habitat V1 (ex. SAV, STA, JEB, OUE, BAT, PIS) ; âge et sexe V4 (M, F, I ; AD, SA, JU, JA, IND) ; fiabilité de l'identification V5 (1 certaine, 2 probable, 3 possible)
  • Le dictionnaire ne donne aucun code espèce pour les insectes : écrire le nom complet.

Darwin Core : une ligne événement par station-nuit (eventID, eventDate, eventTime, samplingProtocol, sampleSizeValue, sampleSizeUnit, decimalLatitude, decimalLongitude, habitat, recordedBy) et une ligne occurrence par observation (scientificName, individualCount, sex, lifeStage, identificationQualifier, associatedMedia). Une nuit sans insecte reste une ligne événement avec zéro occurrence.

استمارة البيانات (BHD26)

لا تخترع رمزًا في الميدان أبدًا: إن كان الرمز غير موجود فاكتب الاسم الكامل.

  • سطر واحد = ملاحظة واحدة، ونوع واحد في كل سطر. لا تترك خانة فارغة أبدًا: اكتب NA أو ND. الصفر يعني أنه جرى البحث ولم يُعثر على شيء.
  • لا وحدة داخل الخانة. الفاصل العشري نقطة. قلم رصاص 2H، وتُملأ الاستمارة في المكان.
  • التاريخ بصيغة AAAA-MM-JJ (2026-09-16)؛ الوقت HH:MM بنظام 24 ساعة، التوقيت UTC+1.
  • خط العرض وخط الطول بالدرجات العشرية، WGS 84، خمس خانات عشرية؛ دقة GPS بالأمتار.

المعرّفات

  • محطة مصيدة الضوء: BHD26_LT01 وLT02
  • العيّنة (حشرة): BHD26_E001 (ترقيم متصل)
  • المراقب: ثلاثة أحرف أولى فريدة (مثل ZBO)

المفردات المضبوطة

  • الطقس V6، يُسجَّل في بداية كل وحدة معاينة وفي نهايتها: الغطاء السحابي بالأوكتا من 0 إلى 8؛ الرياح بمقياس بوفورت من 0 إلى 12؛ المطر 0 لا مطر، 1 رذاذ، 2 زخّة؛ درجة الحرارة بالدرجة المئوية عددًا صحيحًا؛ القمر NL وPQ وPL وDQ (محاق، تربيع أول، بدر، تربيع أخير)
  • الموئل V1 (مثل SAV وSTA وJEB وOUE وBAT وPIS)؛ الجنس والعمر V4 (M وF وI؛ AD وSA وJU وJA وIND)؛ موثوقية التعرّف V5 (1 مؤكد، 2 محتمل، 3 ممكن)
  • لا يورد القاموس رموز أنواع للحشرات: اكتب الاسم الكامل.

Darwin Core: سطر حدث لكل محطة-ليلة (eventID وeventDate وeventTime وsamplingProtocol وsampleSizeValue وsampleSizeUnit وdecimalLatitude وdecimalLongitude وhabitat وrecordedBy) وسطر ظهور لكل ملاحظة (scientificName وindividualCount وsex وlifeStage وidentificationQualifier وassociatedMedia). الليلة التي لا تُجمع فيها حشرات تبقى سطر حدث مع صفر ظهور.
