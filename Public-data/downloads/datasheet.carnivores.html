Datasheet (BHD26)

Event table, one row per sampling unit (station-night): eventID, eventDate (YYYY-MM-DD), eventTime (HH:MM, UTC+1), samplingProtocol, sampleSizeValue, sampleSizeUnit, decimalLatitude, decimalLongitude (WGS 84, 5 decimals), coordinateUncertaintyInMeters, geodeticDatum, locality, habitat, recordedBy, equipe.

Occurrence table, one row per observation: occurrenceID, eventID, scientificName, vernacularName, codeEspece, individualCount, sex, lifeStage, basisOfRecord, identificationQualifier, identifiedBy, associatedMedia, occurrenceRemarks.

  • Station: BHD26_CT01 to CT04. Sample: BHD26_E001 onward. Observer: three unique initials. Team: A, B, C or D.
  • Evidence type (V3): VIS seen, EMP footprint, FEC scat, TER den, OSS bones or meal remains, PHO camera-trap photo.
  • Species codes: HYHY Hyaena hyaena, CAAU Canis lupaster, VUVU Vulpes vulpes, VURU Vulpes rueppellii, CACA Caracal caracal, FELY Felis lybica.
  • Human-wildlife interaction (V7), for example PRE, DEG, PAT, CHI, PIE, TIR, MOR.
  • Sex and age (V4): M / F / I; AD, SA, JU, JA, IND. Reliability (V5): 1 certain, 2 probable, 3 possible.
  • Rules: one line is one observation; never leave a cell empty (NA or ND); 0 means searched and not found.

Fiche de données (BHD26)

Table Événement, une ligne par unité d'échantillonnage (station-nuit) : eventID, eventDate (AAAA-MM-JJ), eventTime (HH:MM, UTC+1), samplingProtocol, sampleSizeValue, sampleSizeUnit, decimalLatitude, decimalLongitude (WGS 84, 5 décimales), coordinateUncertaintyInMeters, geodeticDatum, locality, habitat, recordedBy, equipe.

Table Occurrence, une ligne par observation : occurrenceID, eventID, scientificName, vernacularName, codeEspece, individualCount, sex, lifeStage, basisOfRecord, identificationQualifier, identifiedBy, associatedMedia, occurrenceRemarks.

  • Station : BHD26_CT01 à CT04. Échantillon : BHD26_E001 et suivants. Observateur : initiales sur 3 lettres, uniques. Équipe : A, B, C ou D.
  • Type d'indice (V3) : VIS animal vu, EMP empreinte, FEC fèces, TER terrier ou gîte, OSS ossements ou reste de repas, PHO photo de piège photographique.
  • Codes espèces : HYHY Hyaena hyaena, CAAU Canis lupaster, VUVU Vulpes vulpes, VURU Vulpes rueppellii, CACA Caracal caracal, FELY Felis lybica.
  • Interaction homme-faune (V7), par exemple PRE, DEG, PAT, CHI, PIE, TIR, MOR.
  • Sexe et âge (V4) : M / F / I ; AD, SA, JU, JA, IND. Fiabilité (V5) : 1 certaine, 2 probable, 3 possible.
  • Règles : une ligne = une observation ; jamais de case vide (NA ou ND) ; 0 signifie recherché et non trouvé.

جدول الحدث: صف واحد لكل وحدة أخذ عينات (محطة-ليلة). أسماء الحقول بالإنجليزية كما في القاموس. التاريخ بصيغة AAAA-MM-JJ، والتوقيت HH:MM بتوقيت UTC+1، والإحداثيات WGS 84 بخمس خانات عشرية.

Occurrence: occurrenceID, eventID, scientificName, vernacularName, codeEspece, individualCount, sex, lifeStage, basisOfRecord, identificationQualifier, identifiedBy, associatedMedia, occurrenceRemarks

جدول المشاهدة: صف واحد لكل مشاهدة، مرتبط بمعرّف الحدث eventID.

  • المحطة: من BHD26_CT01 إلى CT04. العيّنة: BHD26_E001 وما يليها. المراقب: ثلاثة أحرف أولى فريدة. الفريق: A أو B أو C أو D.
  • نوع الدليل (V3): VIS حيوان مرئي، EMP أثر قدم، FEC فضلات، TER وكر أو مأوى، OSS عظام أو بقايا وجبة، PHO صورة كاميرا مفخّخة.
  • رموز الأنواع: HYHY Hyaena hyaena، CAAU Canis lupaster، VUVU Vulpes vulpes، VURU Vulpes rueppellii، CACA Caracal caracal، FELY Felis lybica.
  • التفاعل بين الإنسان والحياة البرية (V7)، مثل PRE وDEG وPAT وCHI وPIE وTIR وMOR.
  • الجنس والعمر (V4): M / F / I؛ AD وSA وJU وJA وIND. الموثوقية (V5): 1 مؤكدة، 2 محتملة، 3 ممكنة.
  • القواعد: سطر واحد لكل مشاهدة؛ لا خانة فارغة أبدًا (NA أو ND)؛ الصفر يعني بحثنا ولم نجد.
